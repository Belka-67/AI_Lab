# Лаборатория данных — учебное приложение для 5–8 классов

Игра для 5–8 классов: ученики создают данные о яблоках и грушах, обучают три простые модели и проверяют их на новых карточках. Работает локально в браузере; после первой установки библиотек интернет не нужен.

## Запуск на macOS и Linux

Установите Python 3.11 или новее, если он еще не установлен. Распакуйте архив и откройте терминал в папке `ml_school_lab`. Выполните:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

При первой установке библиотек нужен интернет. Позже для повторного запуска достаточно последней команды. На macOS можно также запустить `START_MAC_LINUX.command` из распакованной папки.

## Запуск на Windows

1. Установите Python 3.11 или новее с сайта python.org, если он еще не установлен. При установке включите **Add python.exe to PATH**.
2. Распакуйте ZIP-файл целиком в папку на компьютере.
3. Дважды нажмите `START_WINDOWS.bat`. При первом запуске скрипт установит библиотеки: нужен интернет, это может занять несколько минут.
4. Приложение откроется в браузере. Если вкладка не открылась, перейдите по адресу, который указан в окне запуска (обычно `http://localhost:8501`). Не закрывайте окно запуска во время показа.

Если установлен Python, можно запустить и через терминал в папке проекта:

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

## Инструкция к уроку для ученика

1. Открой в приложении «Инструкцию к уроку». Посмотри на график: точки — это яблоки и груши, а фон — ответы модели.
2. Сравни, сколько ответов было правильными для знакомых и новых карточек.
3. Создай **12 карточек** и нажми **«Обучить три модели»**. Запомни результат на новых карточках.
4. Создай **60 карточек**, обучи модели и сравни результат с прошлым опытом.
5. Поставь **30% перепутанных меток**, снова создай выборку и обучи модели. Как изменились ответы?
6. По очереди попробуй добавить ошибку измерений и выбросы. После каждого изменения создавай выборку и обучай модели.
7. Посмотри, сколько **яблок и груш** распознано отдельно, и изучи таблицу ошибок.
8. Выбери признаки нового объекта и посмотри объяснение выбранной модели: соседей, вопросы дерева или линию границы.
9. Открой вкладки **«История опытов»** и **«Миссии»**. Какой вывод ты можешь сделать о данных и ответах модели?

Чтобы сравнить влияние одной настройки, оставляй остальные без изменений. Если результат удивил, нажми **«Другой случайный набор»** и повтори опыт.

Каждый раз проверка идет на **одних и тех же 120 новых карточках**, не использованных при обучении: 24 яблока и 96 груш. Такая пропорция помогает увидеть, почему 80% общей точности может скрывать полный провал на яблоках. Рядом с общим результатом показаны результаты по каждому классу и матрица ошибок. Тестовые карточки имеют фиксированный умеренный естественный разброс и не содержат добавленных ошибок измерения, неверных меток и выбросов. Проверка показывает, как модель переносит обучение на этот неизменный набор; он не обязан повторять состав учебных карточек.

Настройки данных действуют независимо:

- **Количество карточек** и **доля яблок** задают размер и настоящий баланс классов.
- **Разброс признаков** означает естественное различие плодов одного класса. При большем разбросе классы чаще перекрываются.
- **Ошибка измерений** добавляет случайную погрешность к записанным размеру и округлости. 0% означает отсутствие дополнительной погрешности.
- **Перепутанные метки** меняют учебную подпись части карточек, сохраняя их настоящий класс.
- **Выбросы** создают необычные плоды, признаки которых похожи на другой класс. Настоящий класс и учебная метка остаются верными; выбросы помечены синим ромбом на графике и в таблице.

Обычная кнопка **«Создать выборку»** сохраняет случайную основу данных между опытами: удобно менять один ползунок и сравнивать. Кнопка **«Другой случайный набор»** создаёт новую основу. Проценты меток и выбросов округляются до целого числа карточек. После изменения данных нужно снова нажать **«Обучить три модели»**.

## Модели, история и миссии

Три модели: ближайшие соседи (**k = 1, 3, 5, 7, 9**), дерево решений (**глубина 1–8**) и логистическая регрессия. Для выбранного объекта приложение показывает ближайших соседей, путь дерева или прямую границу. Если k больше числа учебных карточек, используется наибольшее доступное нечётное число соседей.

История хранит настройки, размер, баланс, неверные метки, выбросы и результат **каждой** модели на новых карточках. График показывает изменения между опытами. Можно загрузить прежний опыт как базовый: восстановятся его карточки, настройки и случайная основа. После этого измените один параметр, создайте выборку при необходимости и обучите модели.

Во вкладке **«Миссии»** есть шесть заданий: мало данных, перепутанные метки, редкое яблоко, выбросы, глубокое дерево и исправление плохого набора. Кнопка начала миссии загружает её исходные настройки. Обучайте модели во вкладке «Лаборатория»; приложение проверяет, какие опыты проведены. Для сравнительных миссий нужны два опыта с одной случайной основой и одинаковыми остальными настройками. Миссия по исправлению данных требует сначала обучить предложенный плохой набор, затем получить не менее 85% на новых карточках хотя бы у одной модели.

Для 7–8 класса под результатом есть раскрываемое объяснение терминов accuracy, recall, confusion matrix и test set. Обучающие баллы сверяются с учебными метками, включая перепутанные; проверочные — с настоящими классами.

Карточки, история и прогресс миссий существуют только в памяти запущенного приложения; после закрытия они не сохраняются. Это учебная симуляция: условные признаки не описывают настоящие яблоки и груши.

## Проверка проекта

В папке `ml_school_lab` после установки зависимостей выполните `python -m unittest discover -s tests`. Проверки охватывают генерацию данных, метрики по классам, объяснения моделей и условия всех шести миссий.
